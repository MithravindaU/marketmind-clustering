## 🚀 Overview

MarketMind Clustering is a customer segmentation project that uses K-Means clustering to identify groups of customers with similar purchasing characteristics.

By analyzing income and spending behavior, the system discovers natural customer segments that can support marketing, business intelligence, and customer analytics strategies.

- K-Means Clustering
